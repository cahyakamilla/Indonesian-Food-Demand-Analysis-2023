# Indonesian-Food-Demand-Analysis-2023
Undergraduate research project on household food demand analysis in Indonesia using Susenas data and the QUAIDS approach. This repository contains thesis presentation materials and quantitative analysis related to consumption behavior and food expenditure patterns.
## Research Topics\
- Food demand analysis
- Household consumption
- Econometrics
- Indonesian socioeconomic issues
